# Technology Information Website

A modern, responsive website showcasing information about technology, its history, uses, and implications.

## Features

- Clean and modern design
- Responsive layout
- Login functionality
- Information about technology history
- Technology applications and implications
- Modern CSS styling

## Technologies Used

- HTML5
- CSS3
- Modern web design principles

## Setup

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the website using the navigation menu

## Project Structure

```
├── index.html          # Main page
├── login.html          # Login page
├── styles.css          # Main stylesheet
├── images/            # Image assets
└── README.md          # Project documentation
```
